# Authorization matrix

Generated from typed endpoint policies. Regenerate with `cargo run -p capsulet-api --bin export-authorization`.

Authentication, token scope, and the role in the selected project must all permit an operation.
Database service accounts never grant platform-admin rights; explicit scopes are a ceiling.
An unknown role grants nothing. Membership endpoints select their project from the path.
Resource reads with missing or mismatched ownership return a generic `404`; selecting a project
without membership or lacking action permission returns `403`. Webhooks require their own signature.
